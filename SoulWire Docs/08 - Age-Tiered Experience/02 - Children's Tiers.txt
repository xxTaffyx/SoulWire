SOULWIRE - CHILDREN'S TIERS

GROWING UP WITH SOULWIRE

Detailed breakdown of how SoulWire adapts across childhood and adolescence.


INFANT/TODDLER (0-2)

Reality:
- Parents use SoulWire for child
- Child doesn't have own account
- Baby tracking features for parents
- No child-facing technology

Parent Features:
- Feeding tracking
- Sleep tracking
- Development milestones
- Doctor appointment management


PRESCHOOL (3-5)

Introduction to Technology:
- Very limited access
- Parent-controlled completely
- Simple educational content
- Voice interaction with Tilda
- Minimal screen time

Features:
- Educational games
- Story time
- Simple creative tools
- Voice assistant (kid-safe)


EARLY ELEMENTARY (6-8)

Expanding Capability:
- Own profile (within family account)
- Educational focus
- Homework help
- Family messaging
- More creative tools

Restrictions:
- No internet access
- Family communication only
- Parent approval for everything
- Screen time limited


LATE ELEMENTARY (9-11)

More Independence:
- More features unlocked
- Some internet (heavily filtered)
- Friend messaging (parent approved)
- More responsibility
- Beginning financial concepts

Restrictions:
- Internet filtered
- Communication monitored
- Content moderated
- Parent visibility high


MIDDLE SCHOOL (12-14)

Significant Growth:
- Most features available
- Social features (safe)
- More internet access (filtered)
- Real responsibilities
- Financial basics

Restrictions:
- Content still filtered
- Some oversight
- Safety features active
- Age-restricted content blocked


HIGH SCHOOL (15-17)

Near-Adult:
- Most adult features
- Preparing for independence
- Significant autonomy
- Real financial management
- Career/college exploration

Restrictions:
- Adult content still blocked
- Safety features maintained
- Reduced parent oversight
- Preparing for transition


THE TRANSITION

At 18:
- Full adult account
- All features unlocked
- Parental oversight removed
- Complete independence
- Full responsibility
