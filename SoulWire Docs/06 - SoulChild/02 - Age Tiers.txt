SOULWIRE - SOULCHILD AGE TIERS

AGE-APPROPRIATE EXPERIENCE

SoulChild adapts to the child's age, providing appropriate features and restrictions at each stage of development.


TODDLER/PRESCHOOL (2-5)

Features:
- Simple games
- Educational content
- Parent-controlled media
- Voice interaction with guardians
- Simple creative tools

Restrictions:
- No messaging
- No browsing
- No social features
- Parent-only settings
- Very limited screen time options

Guardian Interaction:
- Tilda tells stories and teaches
- May helps with emotions (simple)
- Very gentle, very simple


EARLY ELEMENTARY (6-8)

Features:
- Educational games
- Homework help (Tilda)
- Creative tools
- Approved messaging (family only)
- Reading support
- Simple organization (Betsy)

Restrictions:
- Family communication only
- No public internet
- Content heavily filtered
- Parent approval required
- Screen time limits

Guardian Interaction:
- Tilda for learning
- Betsy for simple schedule
- May for emotional check-ins
- Age-appropriate conversation


LATE ELEMENTARY (9-11)

Features:
- More advanced education
- Research with Clara (filtered)
- Creative projects
- Approved friend messaging
- More responsibility
- Task management

Restrictions:
- Internet filtered
- Communication monitored
- Social features limited
- Parent approval for new contacts
- Screen time awareness

Guardian Interaction:
- Fuller Guardian capability
- Still age-appropriate
- More independent use
- Parent visibility


MIDDLE SCHOOL (12-14)

Features:
- Expanded capabilities
- More internet access (filtered)
- Social features (safe)
- Financial basics (SoulBank junior)
- More autonomy
- Privacy increasing

Restrictions:
- Content still filtered
- Some parental oversight
- Safety features active
- Gradual responsibility

Guardian Interaction:
- Near-full capability
- More sophisticated
- More independence
- Still protected


HIGH SCHOOL (15-17)

Features:
- Most adult features
- Preparation for independence
- Financial management learning
- Career exploration
- College/future planning
- Significant autonomy

Restrictions:
- Age-restricted content blocked
- Safety features maintained
- Parent visibility (reduced)
- Preparing for adult transition

Guardian Interaction:
- Full interaction
- Treats as young adult
- Preparing for independence


TRANSITION TO ADULT

At 18:
- Full SoulWire access
- Parental controls removed
- Adult account
- All features
- Full responsibility
