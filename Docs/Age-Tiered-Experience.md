## Baby-Facing Content (VERY LIMITED)

**Reality:** Sometimes parents need to put baby down safely and do something.   If screen is used:

| Content | Why | Time Limit |
|---------|-----|------------|
| **High-contrast patterns** | Newborn vision is limited | 5-10 min max |
| **Slow-moving black/white shapes** | What they can actually see | |
| **Parent face videos** | Familiar, comforting | |
| **Soft lullabies** | Calming | |

**What SoulTV shows newborns:**
- Black and white patterns
- Very slow movement
- Simple shapes
- Parent face recordings
- Soft music

**NOT:**
- Bright colors (can't see well yet)
- Fast movement (overwhelming)
- Complex images (can't process)
- Loud sounds (startling)

## Time Limits (ENFORCED)

| Limit | Details |
|-------|---------|
| **Max 10-15 minutes** | Then screen goes to "cuddle time" message |
| **Cannot extend** | Hard limit |
| **Parent notification** | "Baby's screen time done — time for cuddles!" |
| **Tracking** | Parents see total screen time |

## Soul for Newborns

Soul is **NOT interactive** with newborns.  Soul helps PARENTS:

| Soul Does | For |
|-----------|-----|
| "Baby might be hungry — last feeding was 3 hours ago" | Parent |
| "Baby's sleep pattern suggests overtired" | Parent |
| "Remember: tummy time today!" | Parent |
| "You're doing great, new parent" | Parent support |
