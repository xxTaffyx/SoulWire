# SoulWire Repo Map

## Top Level
- `Docs/` = global documentation for the whole SoulWire ecosystem
- `Apps/` = app and product folders
- `Shared/` = shared assets, brand, design tokens, and reusable references
- `Soulasm/` = low-level assembler and VM work
- `SoulLang/` = language development
- `SoulCore/` = core libraries/runtime
- `SoulOS/` = operating system layer

## Shared Rules
- Global docs live in `Docs/`
- App-specific docs live inside that app folder under `docs/`
- Shared images, icons, audio, and videos live in `Shared/Assets/`
- Shared colors, brand, and UI tokens live in `Shared/Brand/` and `Shared/Design/`

## Apps
- `Apps/Vortexian/` = Vortexian app docs, code, and assets
- `Apps/Soulwire-Website/` = website project docs and code
- `Apps/SoulLang/` = language-facing app/project docs
- `Apps/SoulOS/` = OS-facing app/project docs
- `Apps/SoulCore/` = shared runtime/core project docs
