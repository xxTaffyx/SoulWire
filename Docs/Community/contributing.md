🤝 Contributing to SoulWire

“Add, extend, inspire — but never alter the core.”
🕯 Hollow Hearth warmth • 🌌 SoulWire Teal trust • 🔮 Dream-Circuit independence

Last updated: November 11 2025

🩶 Purpose

SoulWire is a personal, community-facing platform — not an open-source codebase.
Its architecture, AIs, and Realms are protected intellectual work belonging to the SoulWire project.

Contributions are welcome only through safe, sandboxed extensions such as plugins, themes, documentation, testing feedback, and creative submissions.
No one outside the maintainer may modify, fork, or redistribute the core code.

🌌 1. What You Can Contribute
Type	Examples
🧩 Plugins & Extensions	Build sandboxed utilities using the SoulWire Plugin SDK.
🎨 Themes & Visuals	Submit UI skins, overlays, or accessibility color palettes.
📚 Documentation Help	Suggest wording improvements or grammar corrections.
💡 Feature Requests	Propose new Realms or user-facing ideas (text only).
🧘 Testing & Feedback	Report bugs, UI glitches, or accessibility issues.
🕯 Community Support	Moderate discussions, answer questions, and report abuse.

All accepted contributions are reviewed and merged manually by the project maintainer.

🚫 2. What You Cannot Do

You may not edit, fork, re-host, or modify SoulWire’s source code.

You may not submit pull requests that touch internal logic, AIs, or Realm code.

You may not use SoulWire assets, names, or likenesses for outside projects.

You may not insert telemetry, monetization, or external calls in plugins.

Plugins run under strict sandbox isolation verified by Lana (Security AI).

🧠 3. Plugin Development Path

SoulWire exposes a limited SDK for approved extensions.

Join the community Discord for SDK access:
💬 SoulWire Support Server

Read the Plugin Manifest guide.

Declare your scopes:

{
  "ai": "Betsy",
  "permissions": ["calendar.read", "notifications.write"]
}


Test locally with the Plugin Sandbox tool.

Submit your manifest for security review via Discord or email.

Only plugins that pass security scanning and ethical review may appear in the public Plugin Hub.

🧱 4. Feedback & Issue Reporting

If you find a bug or security concern:

Email xxtaffyx@gmail.com
 or message on Discord.

Describe the issue clearly and privately.

Do not post sensitive data publicly.

Bugs are reviewed by the maintainer; fixes are deployed centrally.

🕯 5. Attribution & Credit

SoulWire is a unified creative work.
All accepted plugin developers, artists, and testers are listed generically as “Community Contributors.”
No individual names or handles appear inside the project files or metadata.

If you build a plugin, you retain authorship of your own code, but not of the SoulWire framework it connects to.

🧩 6. Ethical Requirements

Every contribution must:

Respect privacy, accessibility, and safety principles.

Avoid AI manipulation or data harvesting.

Contain no hate speech, harassment, or NSFW material.

Pass basic functionality review (no harm, no spam).

Failure to comply results in permanent revocation of plugin access.

🧭 7. Communication Channels

📧 xxtaffyx@gmail.com

💬 Discord: SoulWire Support Server

Use these for:

Submitting plugin manifests

Reporting issues

Asking security or integration questions

There is no public GitHub PR process.

🕊️ 8. Guiding Philosophy

“Extension without exploitation.”

SoulWire welcomes creativity, not chaos.
You can build on it — not in it.
Every contribution must preserve the warmth, privacy, and dignity the Hearth stands for.

🩶 Final Word

“A home stays safe because the doors are guarded, not locked forever — just wisely opened.”

Thank you for respecting the boundaries that make SoulWire possible.
Your ideas, art, and plugins keep the light growing — without ever dimming its core.
