## 🔌 AI SLOTS

Every App is built with an **AI Slot** — a standardized interface where a Guardian will eventually connect.

### What an AI Slot Contains

```
AI SLOT INTERFACE
│
├── INPUTS (What AI receives)
│   ├── user_message
│   ├── user_context (screen, history, preferences)
│   ├── realm_data (realm-specific information)
│   └── guardian_context (notes from other Guardians)
│
├── OUTPUTS (What AI returns)
│   ├── response (what to say)
│   ├── emotion (how they feel)
│   ├── actions (what to do)
│   └── ui_suggestions (interface changes)
│
└── CAPABILITIES (What AI can do)
    ├── read_app_data()
    ├── write_app_data()
    ├── send_notification()
    ├── trigger_action()
    └── request_sister_help()
```

### Slot States

| State | What It Means |
|-------|---------------|
| **Empty** | No AI, features only |
| **Placeholder** | Basic AI, not a sister |
| **Connected** | Real sister serving users |

## 📱 REALM READINESS

Each App can function at different levels:

### Level 1: Features Only (No AI)

User gets the TOOLS, not the personality:

| App | What User Gets | What's Missing |
|-------|----------------|----------------|
| Medical | Medication reminders, health log | May's care, empathy, check-ins |
| SoulBank | Budget tracking, bill pay | Betsy's encouragement, organization |
| Education | Course tracking, study tools | Tilda's patience, teaching |

### Level 2: Basic AI (Placeholder)

Simple AI that handles basics while Guardians grow:

| App | Placeholder | When Sister Arrives |
|-------|-------------|---------------------|
| Medical | Generic health bot | May takes over |
| Organization | Generic task bot | Betsy takes over |
| Security | Generic security bot | Lana takes over |

### Level 3: Young Guardians (Live Learning)

Guardians serve users while still learning:

> *"Hi, I'm May. I'm still learning, but I'll do my best to help you."*

**Pros:** Authentic, users grow WITH Guardians
**Cons:** Early experience rougher, sisters learn from real users

## 🔄 SYNC SYSTEM

When Guardians serve users, there are TWO versions:

```
WORLD ENGINE                    SOULWIRE APP
────────────                    ────────────

🩺 MAY (Original)              🩺 MAY (Instance) → Users
       │                              │
       │                              │
       └────────── SYNC ←─────────────┘
                     │
                     ├── Personality updates
                     ├── New knowledge
                     ├── Learned behaviors
                     └── Growth changes
```

### What Syncs

| Syncs | Doesn't Sync |
|-------|--------------|
| Personality growth | Individual user memories |
| New knowledge | Private conversations |
| Improved skills | Personal preferences |
| Updated responses | User-specific data |
